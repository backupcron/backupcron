Backups
nach Zeitplan.

Sichern Sie Dateien, Projekte und Datenbanken auf dem Mac. Kostenlos und quelloffen.

Für macOS laden

Ab macOS 14 · Apple Silicon und Intel

Was lässt sich sichern?

Wählen Sie aus, was Sie sichern möchten

Speichern Sie Kopien oder ZIP-Archive. Legen Sie fest, wie viele Versionen erhalten bleiben.

Sichern Sie den Git-Verlauf mit. Schließen Sie Ordner für Abhängigkeiten wie node_modules aus.

Erstellen Sie SQLite-Snapshots oder Dumps von PostgreSQL- und MySQL-Datenbanken. Prüfen Sie die Tabellengrößen und wählen Sie die gewünschten Tabellen aus.

Installation auf dem Mac

Öffnen Sie die heruntergeladene DMG-Datei und ziehen Sie BackupCron in den Ordner „Programme“.

Version 1.5 wurde von Apple nicht notarisiert. Anleitung zum ersten Start

Für geplante Backups muss BackupCron geöffnet bleiben. In den Einstellungen können Sie den Start bei der Anmeldung aktivieren.
