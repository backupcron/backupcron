Guarda archivos, proyectos y bases de datos en tu Mac con una aplicación gratuita y de código abierto.

Descargar para macOS

macOS 14 o posterior · Apple Silicon e Intel

Qué puedes guardar

Elige qué quieres guardar

Guarda copias sin comprimir o en formato ZIP. Elige cuántas versiones recientes conservar.

Incluye el historial de Git en la copia. Excluye carpetas de dependencias como node_modules.

Crea instantáneas de SQLite y volcados de PostgreSQL o MySQL. Consulta el tamaño de las tablas y elige cuáles guardar.

Instalación en Mac

Abre el archivo DMG que has descargado y arrastra BackupCron a la carpeta Aplicaciones.

La versión 1.5 no está notarizada por Apple. Cómo abrir la aplicación por primera vez

Deja BackupCron abierto para que se ejecuten las copias programadas. En los ajustes puedes activar la apertura de la aplicación al iniciar sesión en macOS.
