Sauvegardes
planifiées.

Sauvegardez vos fichiers, projets et bases de données sur Mac. Une application gratuite et open source.

Télécharger pour macOS

macOS 14 ou ultérieur · Puces Apple et Intel

Que peut-on sauvegarder ?

Choisissez les données à sauvegarder

Enregistrez des copies simples ou des archives ZIP. Choisissez le nombre de versions à conserver.

Incluez l’historique Git dans la sauvegarde. Excluez les dossiers de dépendances comme node_modules.

Créez des instantanés SQLite ou des exports SQL de PostgreSQL et MySQL. Vérifiez la taille des tables et choisissez celles à sauvegarder.

Installation sur Mac

Ouvrez le fichier DMG téléchargé et faites glisser BackupCron dans le dossier Applications.

La version 1.5 n’a pas été notariée par Apple. Guide du premier lancement

Laissez BackupCron ouvert pour que les sauvegardes planifiées s’exécutent. Vous pouvez activer le lancement à l’ouverture de session dans les réglages.
