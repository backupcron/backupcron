Backup
programmati.

Esegui il backup di file, progetti e database sul Mac. L’app è gratuita e open source.

Scarica per macOS

macOS 14 o successivo · Apple Silicon e Intel

Di cosa puoi fare il backup?

Scegli cosa salvare

Salva i file come copie o archivi ZIP. Scegli quante versioni recenti conservare.

Includi la cronologia Git nel backup. Escludi le cartelle delle dipendenze come node_modules.

Crea istantanee di SQLite o dump SQL di PostgreSQL e MySQL. Controlla le dimensioni delle tabelle e scegli quali salvare.

Installazione sul Mac

Apri il file DMG scaricato e trascina BackupCron nella cartella Applicazioni.

La versione 1.5 non è stata autenticata da Apple. Guida al primo avvio

Lascia aperto BackupCron per eseguire i backup programmati. Nelle impostazioni puoi attivare l’avvio automatico all’accesso a macOS.
