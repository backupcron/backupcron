決めた時刻に
バックアップ

Macでファイル、プロジェクト、データベースをバックアップ。無料で使えるオープンソースのアプリです。

macOS版をダウンロード

macOS 14以降 · Appleシリコン搭載MacとIntel Macに対応

バックアップできるもの

バックアップ対象を選択

そのままコピーするか、ZIP形式で保存できます。直近の何世代分を残すかも選べます。

Gitの履歴をバックアップに含められます。node_modulesなど、依存関係を格納するフォルダは除外できます。

SQLiteのスナップショットやPostgreSQL、MySQLのダンプを作成できます。テーブルごとのサイズを確認し、保存するテーブルを選べます。

Macにインストール

ダウンロードしたDMGを開き、BackupCronを「アプリケーション」フォルダにドラッグします。

バージョン1.5はAppleの公証を受けていません。 初回起動の手順

スケジュールどおりにバックアップするには、BackupCronを起動したままにしてください。設定で、macOSへのログイン時に自動起動するようにできます。
