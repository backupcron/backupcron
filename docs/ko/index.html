Mac에서 파일, 프로젝트, 데이터베이스를 백업하세요. 무료로 사용할 수 있는 오픈 소스 앱입니다.

macOS용 다운로드

macOS 14 이상 · Apple Silicon 및 Intel Mac 지원

백업할 수 있는 항목

백업할 항목 선택

원본 형식 그대로 복사하거나 ZIP 파일로 저장하세요. 최근 백업을 몇 개까지 보관할지도 선택할 수 있습니다.

백업에 Git 기록을 포함할 수 있습니다. node_modules 같은 의존성 폴더는 제외할 수 있습니다.

SQLite 스냅샷과 PostgreSQL 또는 MySQL 덤프를 만들 수 있습니다. 테이블 크기를 확인한 뒤 저장할 테이블을 선택하세요.

Mac에 설치하기

다운로드한 DMG를 열고 BackupCron을 응용 프로그램 폴더로 드래그하세요.

버전 1.5는 Apple의 공증을 받지 않았습니다. 처음 실행하는 방법

예약한 시간에 백업하려면 BackupCron을 실행한 상태로 두세요. 설정에서 macOS 로그인 시 자동 실행을 켤 수 있습니다.
