按原样复制文件或保存为 ZIP 压缩包。你可以指定保留最近的几份备份。

在 Mac 上安装

打开下载的 DMG 文件，将 BackupCron 拖入“应用程序”文件夹。

要按计划执行备份，请保持 BackupCron 运行。你可以在设置中启用登录 macOS 时自动启动。
